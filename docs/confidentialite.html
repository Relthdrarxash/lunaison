Politique de confidentialité

Dernière mise à jour : 4 novembre 2026.

En bref : Lunaison ne collecte aucune donnée. Tout ce que vous saisissez reste sur votre téléphone. Il n'y a ni compte, ni serveur, ni publicité, ni outil de mesure d'audience.

Ce que l'application enregistre

Sur votre téléphone, et uniquement sur votre téléphone :

  • les journées que vous notez : flux, douleur, symptômes, humeurs et notes personnelles ;
  • vos réponses au démarrage : tranche d'âge, date approximative des dernières règles, durée habituelle du cycle ;
  • vos réglages de rappels ;
  • si vous utilisez le partage, le prénom, le numéro et la messagerie de la personne choisie.

Ces informations concernent votre santé et votre vie intime. C'est pour cette raison qu'elles ne quittent jamais votre téléphone du fait de Lunaison.

Ce que nous recevons

Rien. Lunaison n'a pas la permission d'accéder à Internet : elle ne peut techniquement rien envoyer. Personne, pas même l'auteur de l'application, n'a accès à vos données.

Pas de sauvegarde dans le nuage

Lunaison exclut ses données de la sauvegarde Android et du transfert vers un nouveau téléphone. Pour les conserver, utilisez l'export au format tableur dans les réglages : vous choisissez où enregistrer le fichier.

Le partage avec un ou une partenaire

Lunaison prépare un message et ouvre la messagerie que vous avez choisie (SMS, WhatsApp, Signal ou une autre application). C'est vous qui l'envoyez. Ce message est alors traité par cette messagerie, selon ses propres règles, comme n'importe quel autre message. Lunaison ne garde aucune trace de l'envoi.

Pour choisir un contact, Lunaison utilise le sélecteur du système, qui ne lui donne accès qu'au contact choisi. Lunaison ne demande pas l'accès à votre carnet d'adresses.

Les notifications

Les rappels sont calculés et programmés sur votre téléphone. Sur l'écran verrouillé, ils n'affichent que le nom de l'application.

Effacer vos données

Les réglages de Lunaison permettent de tout effacer en un geste. Désinstaller l'application efface aussi toutes ses données.

Le site de Lunaison

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience. Comme tout hébergeur, GitHub peut enregistrer des journaux techniques de connexion (adresse IP, date, heure, page demandée).

Vos droits

Comme aucune donnée personnelle n'est collectée par l'auteur de Lunaison, il n'y a pas de données à consulter, rectifier ou supprimer de notre côté. Pour toute question : escale.apps@proton.me.

Code ouvert

Le code de Lunaison est public et libre : chacun peut vérifier ce qui précède en le lisant sur GitHub.

Lunaison n'est ni un dispositif médical ni une méthode de contraception.
