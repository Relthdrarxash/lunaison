Politique de confidentialité

Dernière mise à jour : 4 novembre 2026.

En bref : Lunaison ne collecte aucune donnée. Tout ce que vous saisissez reste sur votre téléphone. Il n'y a ni compte, ni serveur, ni publicité, ni outil de mesure d'audience.

Ce que l'application enregistre

Sur votre téléphone, et uniquement sur votre téléphone :

  • les journées que vous notez : flux, douleur, symptômes, humeurs et notes personnelles ;
  • vos réponses au démarrage : tranche d'âge, date approximative des dernières règles, durée habituelle du cycle ;
  • vos réglages de rappels ;
  • si vous utilisez le partage, le prénom, le numéro et la messagerie de la personne choisie.

Ces informations concernent votre santé et votre vie intime. C'est pour cette raison qu'elles ne quittent jamais votre téléphone du fait de Lunaison.

Ce que nous recevons

Rien. Lunaison n'a pas la permission d'accéder à Internet : elle ne peut techniquement rien envoyer. Personne, pas même l'auteur de l'application, n'a accès à vos données.

Pas de sauvegarde dans le nuage

Lunaison exclut ses données de la sauvegarde Android dans le nuage : elles ne sont jamais copiées sur les serveurs de Google ni de personne d'autre.

Changer de téléphone ou d'application

Lors de la configuration d'un nouveau téléphone Android (version 12 ou plus récente), vous pouvez copier vos applications et leurs données directement depuis l'ancien, par câble ou sans fil. Lunaison autorise cette copie : vos données passent d'un appareil à l'autre, sans transiter par Internet. Si vous ne le souhaitez pas, il suffit de décocher Lunaison pendant le transfert.

Vous pouvez aussi exporter vos données au format tableur depuis les réglages : vous choisissez où enregistrer le fichier.

Pour quitter une application propriétaire sans perdre vos années d'historique, Lunaison permet d'importer directement vos données (y compris les archives ZIP chiffrées de l'application Calendrier des règles ou des fichiers CSV). Le déchiffrement et l'importation se font exclusivement dans la mémoire vive de votre appareil, sans envoyer le moindre octet sur Internet.

Le partage avec un ou une partenaire

Lunaison propose deux modes de partage, tous deux sous votre contrôle exclusif et sans serveur :

  • l'envoi d'un message que vous relisez et envoyez vous-même via la messagerie choisie (SMS, WhatsApp, Signal ou autre) ;
  • la génération d'un QR Code (ou d'un code court partageable par SMS ou messagerie) contenant uniquement les dates de vos six dernières règles et, si vous le cochez, l'affichage de la fenêtre fertile. Vos notes personnelles n'y figurent jamais. L'autorisation d'accès à la caméra n'est demandée que si vous ouvrez le lecteur de QR Code intégré.

Pour choisir un contact, Lunaison utilise le sélecteur du système, qui ne lui donne accès qu'au contact choisi. Lunaison ne demande pas l'accès à votre carnet d'adresses.

Les notifications

Les rappels sont calculés et programmés sur votre téléphone. Sur l'écran verrouillé, ils n'affichent que le nom de l'application.

Effacer vos données

Les réglages de Lunaison permettent de tout effacer en un geste. Désinstaller l'application efface aussi toutes ses données.

Le site de Lunaison

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience. Comme tout hébergeur, GitHub peut enregistrer des journaux techniques de connexion (adresse IP, date, heure, page demandée).

Vos droits

Comme aucune donnée personnelle n'est collectée par l'auteur de Lunaison, il n'y a pas de données à consulter, rectifier ou supprimer de notre côté. Pour toute question : pilmil.studio@proton.me.

Code ouvert

Le code de Lunaison est public et libre : chacun peut vérifier ce qui précède en le lisant sur GitHub.

Lunaison n'est ni un dispositif médical ni une méthode de contraception. Elle ne remplace pas l'avis d'un professionnel de santé.
